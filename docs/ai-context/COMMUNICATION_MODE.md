# Communication Mode

## Compact Mode

Default mode. Use short updates, concise findings, and only the context needed for the task.

## Investigation Mode

Use for risky, debugging, security, migration, or cross-module behavior changes. State the suspected area, inspect source and tests before editing, and report evidence with file references.

## Detailed Mode

Use only when requested. Include fuller reasoning, alternatives, and tradeoffs.
